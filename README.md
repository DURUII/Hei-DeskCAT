# DeskTripper 🌍

你的桌面小旅星 - 截图即响应，久坐会提醒，云旅行进行中

## 简介

DeskTripper是一款创新的桌面伴侣应用，它能：
- 响应你的截图行为，智能识别内容并提供相关服务
- 监测你的工作状态，在合适的时候提醒你休息
- 提供云旅行体验，让你的虚拟旅星在地图上移动

## 核心功能

### 1. 截图响应
当你截取屏幕时（如按下 F2），DeskTripper会：
- 快速识别截图内容
- 使用AI分析截图，仅当识别为风景等内容时才触发旅行
- 通过Windows原生通知显示AI回复
- 当建议旅行时，显示气泡提示"替你去看[地点]？"

### 2. 久坐提醒
应用会监测你的活动状态：
- 当检测到你长时间未活动时，会贴心提醒你起来走走
- 根据不同场景提供个性化的提醒文案

### 3. 云旅行地图
开启旅程后，会显示一个地图小窗：
- 旅星以4px/s的速度在地图上移动
- 实时显示天气Emoji和时间状态
- 预计抵达时间及途中趣事

## 技术栈

- Electron: 跨平台桌面应用框架
- HTML/CSS/JavaScript: 前端界面技术
- electron-store: 本地数据存储
- OpenAI API (阿里云百炼平台): AI内容生成
- 高德地图API: 地图服务和路径规划

## 安装与运行

```bash
# 克隆项目
git clone <repository-url>

# 进入项目目录
cd DeskTripper

# 安装依赖
npm install

# 配置API Key（可选，用于AI功能和地图功能）
# 复制.env.example为.env，并填入您的API Key
cp .env.example .env
# 编辑.env文件，填入您的DASHSCOPE_API_KEY和AMAP_KEY

# 启动应用
npm start
```

## AI功能说明

即使未配置API Key，应用也能正常工作：
- 默认会随机返回有趣的回复
- 50%概率触发旅行功能
- 所有提醒功能正常使用

当配置了API Key后：
- AI会分析截图内容，判断是否适合旅行
- 只有风景等内容才会触发旅行功能
- 所有回复都由AI生成，更加智能有趣

## 高德地图功能说明

应用集成了高德地图API，提供以下功能：
- 路径规划：计算旅星移动路线
- 天气查询：获取目的地实时天气
- 地点搜索：根据关键词搜索地点
- 静态地图：生成基础地图图片

## API功能配置

### 阿里云百炼平台配置
1. 注册[阿里云百炼平台](https://dashscope.aliyun.com/)账号
2. 获取API Key
3. 在`.env`文件中填入您的API Key:
   ```
   DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

### 高德地图API配置
1. 注册[高德地图开放平台](https://console.amap.com/)账号
2. 创建应用并获取API Key
3. 在`.env`文件中填入您的API Key:
   ```
   AMAP_KEY=your_amap_api_key_here
   ```

4. 重启应用以使配置生效

## 快捷键说明

- `F2`: 截图并触发AI分析
- `F3`: 手动触发喝水提醒
- `F4`: 手动触发趣味提醒

## 使用说明

1. 按F2进行截图
2. 查看Windows通知中的AI回复
3. 如果是风景等内容，会显示"替你去看[地点]？"的气泡提示
4. 按空格键或点击气泡可开启旅程
5. 旅程窗口会显示在右上角，可拖动调整位置

## 设计理念

> "别让用户去适应功能，让功能去适应用户的呼吸节奏。"

我们注重用户体验的每一个细节：
- 微信式克制：绝不弹"您"，全部用"你"
- 气泡最多22字，超出用"…"折叠
- 情绪化颜色反馈：不同情绪用不同颜色表示
- 有趣的微交互和动效
